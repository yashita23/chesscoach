# React + FastAPI thay vì Streamlit

Bản nghiên cứu ban đầu tự mâu thuẫn: có chỗ chọn React + FastAPI, có chỗ dựng khung bằng Streamlit. Nhóm chọn React (Vite) + FastAPI + SQLite, chạy local, để có bàn cờ kéo thả mượt, đăng nhập email + mật khẩu và phân tích ván chạy nền. Đổi lại là C phải gánh cả frontend lẫn auth; người học mô phỏng và lớp 3 vì thế chuyển sang A. Streamlit vẫn là đường lùi nếu cuối tuần 2 chưa chạy được trọn vòng.
